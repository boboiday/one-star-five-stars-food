A one-sentence entry for the make.fun bounty "One Star, Five Stars for the Food": a first-time alien visitor reviews planet Earth with a single star, grumbling about the gravity, the traffic, and the airport queue — while admitting that one specific local dish nearly changed his mind.

## Run it

Requires Node 22. No dependencies, no network access.

```sh
node main.ts
```

The program prints the sentence to stdout and writes the exact same sentence to `/output/entry.txt` (UTF-8, 1–200 characters).
